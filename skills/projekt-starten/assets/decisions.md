# Entscheidungsprotokoll

Hier stehen Entscheidungen, die nicht aus dem Code ersichtlich sind und die ein neuer Chat nicht wieder aufrollen soll. Dazu gehören Stack- und Architekturentscheidungen, neue Abhängigkeiten, bewusst verworfene Ansätze und Ausnahmen vom Standard. Der Agent liest diese Datei, bevor er Architektur vorschlägt oder eine Abhängigkeit hinzufügt, und schlägt keine Ansätze vor, die hier als verworfen stehen.

Eine Entscheidung wird nicht gelöscht. Status sind «vorgeschlagen» (bis Marc die zugehörige Architektur freigibt), «gilt» und «ersetzt» mit Verweis auf die neue. Aufgerollt wird eine Entscheidung nur, wenn Marc es verlangt oder der Agent einen neuen Sachverhalt meldet und Marc zustimmt.

| Nr | Entscheidung | Grund | Verworfene Alternativen | Quelle | Status |
|---|---|---|---|---|---|
| E01 | | | | von Marc, Vorschlag des Agenten oder aus dem Code abgeleitet | gilt |

Für neue Abhängigkeiten mindestens diese Angaben im Grund: wofür sie gebraucht wird, Betreuer, Alter, Anzahl Versionen, Nutzung durch bekannte Projekte, Lizenz, Version und Namensähnlichkeit zu bekannten Paketen. Zusammengehörige Pakete dürfen in einem Eintrag stehen. Nicht ermittelte Angaben (zum Beispiel Downloadzahlen) stehen als «nicht gemessen».
