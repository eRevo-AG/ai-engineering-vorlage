# Konventionen für Spezifikationen

- Ein Feature, eine Spec. Änderungen erweitern die bestehende.
- Kein Code, keine Technik, kein Status.
- Kriterien haben stabile IDs (`<ABK>-<nr>-AK<nr>`, Randfälle `-RF<nr>`) und das Muster Ausgangslage, Handlung, erwartetes Ergebnis. IDs nie umnummerieren, Entfallenes als «entfallen» markieren.
- Sobald es Rollen gibt, beschreibt mindestens ein Kriterium den Verbotsfall.
- Eine freigegebene Spec ändert sich nur mit Zustimmung der Projektleitung. Stimmt sie beim Bauen nicht, melden.
